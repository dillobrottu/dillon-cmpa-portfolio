# Dillon Brown's CMPA Course Portfolio
This is a portfolio dedicated to Dillon Brown's CMPA coursework.
The portfolio will feature the material that I created for the course and an analysis of my actions and choices made during each course.
Each course will have selected activities and projects for display.
The work shown will have a description of my choices and decisions to let the reader know of the process for each subject.

I chose to create a portfolio showcasing all of my work done throughout my programming course history. It serves both as a reminder of my past and as inspiration to myself and potentially others. Allowing myself to look back on my previous work in a convenient manner lets me have easier access to view old material. This allows me, and viewers of the site, to draw inspiration from my old work to use on new projects. 

This is a simple static site built using HTML and CSS. Visual Studio Code was used to edit the code and GitHub Desktop was used to upload the code to the live site. The site is hosted using GitHub Pages. All code is written by Dillon Brown. I chose to use basic tools and editors, as I did not plan to use any outside code or editors. As this is a portfolio, it is a showcase of my work. Using any outside assistance, like artificial intelligence or frameworks, would not be a good representation of my own skills. While the work may be simple, the work is my own.

My progress from the first iteration of project one included adding all the remaining displays. Project two is a finalized version of the site, including all displays and design changes. The main milestone included finalizing each display to include all relevant information and visible project displays. Minor design elements are also included, altering small portions of the site to be more visibly pleasing. I was most focused on ensuring that the site serves its objective. The main purpose of the site is to be a portfolio displaying all my CMPA coursework.
