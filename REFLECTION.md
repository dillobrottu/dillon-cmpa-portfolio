# Project 02: Reflection - Dillon Brown
Throughout this project, one main decision I had to make was how I would structure and build the site. I knew from the start that I would want to make a portfolio based on my work from the CMPA courses. It felt natural that after 8 courses I would want to chronicle my most important features. The major decision would be how I would display each work. I kept each work I completed in a folder containing all of my CMPA course exercises, assignments, and projects. I would have to decide on what is displayed, and how I would showcase it. I decided on choosing each major project in either an iframe displaying the site, or using screenshots based if the project was a site or creation.

I am satisfied with how the portfolio turned out. Each course display showcases my projects done and gives a representation of each major project I have done. The structure of the site was done by reworking code from my old projects. Seen from some of the portfolio work, the layout of the site is common throughout all of my projects. I first started using this layout in 2024, when I first started creating websites. I am unable to remember or find documentation of why I started to use this site layout but it has stuck with me. The layout of the site is quite simple and rudimentary, but it has served me well throughout my entire college career.

When I started out creating the site, I already had an idea of how I would structure and design the site. The layout was already chosen, and I scoped out how I would display each site. As I built the site I reached some hurdles that I had not planned for. Certain projects were not sites that were easily displayed. Projects that were hosted sites were able to be shown using iframes, I had planned to use this tag to display the work for each project. But I failed to account that some courses did not involve creating hosted sites. Certain projects, like ones I created in Figma, needed to be accounted for. If I were to start this project over, I would account for each project and change my approach to how I viewed each project.

While the capstone project is a culmination of everything I have learned from my CMPA course history, this portfolio is a showcase of everything I have done. I learned of the importance of recording and keeping information well documented. In some cases, I had trouble finding in-depth information for some projects as some courses became unavailable to revisit. Keeping record of my work would allow me to revisit and gain inspiration for future work. The CMPA courses have given me a way to hone my programming and site building skills. This project has been an opportunity to revisit and review all of my past work to put on display for others and myself to view at any time.
